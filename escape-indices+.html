Les données

Trier et comprendre l'importance des données pour une IA

📋 Mission

Une intelligence artificielle ne peut fonctionner sans données de qualité. Voici 20 données mélangées sur l'éducation. Certaines sont utiles pour entraîner une IA éducative, d'autres sont incorrectes, inutiles ou protégées par le RGPD.

Votre objectif : Identifiez les 5 données VALIDES et UTILES. Cliquez sur chaque carte pour la retourner et découvrir si elle contient un chiffre. Attention aux données personnelles !

⚠️ Attention : Après 3 erreurs consécutives, les cartes se mélangent ET un indice apparaît !

👆 Cliquez sur les cartes pour les retourner et découvrir les chiffres cachés !
❌ Erreurs consécutives : 0/3
🔄 Les cartes ont été mélangées ! Un nouvel indice apparaît ci-dessous.
💡 Indice 1 : RGPD et données personnelles
Évitez toutes les données personnelles sensibles protégées par le RGPD : régime alimentaire, date de naissance, inscriptions sportives, adresse, numéro de téléphone, photos individuelles. Ces données ne peuvent PAS être utilisées pour entraîner une IA sans consentement. Cherchez uniquement des données agrégées et anonymes.
💡 Indice 2 : Catégories valides
Les données valides concernent uniquement : résultats scolaires globaux (taux de réussite DNB, passage en classe supérieure), organisation (taille classe, temps récréation) et indicateurs sociaux publics (IPS). Tout le reste est soit non pertinent, soit interdit.
💡 Indice 3 : Lettres des bonnes cartes
Les 5 données valides sont les cartes : E, C, G, K, A. Cherchez-les dans la grille mélangée !
💡 Indice 4 : Ordre des chiffres
L'ordre du code final est : E (1ère) → C (2ème) → G (3ème) → K (4ème) → A (5ème). Cliquez dans cet ordre pour découvrir le code !
✨ Indice 5 : Localisation visuelle
Les bonnes cartes vont briller maintenant ! Regardez les cartes qui s'illuminent en vert.
💡 Rappel RGPD : Les données personnelles identifiables (régimes alimentaires, dates de naissance, inscriptions individuelles, adresses, contacts) sont protégées. Seules les données agrégées, anonymes et publiques peuvent être utilisées pour l'IA éducative.
